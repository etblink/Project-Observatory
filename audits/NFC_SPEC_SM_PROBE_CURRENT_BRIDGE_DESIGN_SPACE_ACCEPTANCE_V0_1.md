PASS.

An explicitly new physical-current map is scientifically legitimate if its new content is fully declared rather than disguised as source derivation. Its transformation law, support/profile, operator domain, normalization status, failure conditions, and probe-class scope must be preregistered independently of transition outcomes.

This route minimizes intermediate structure but leaves a comparatively large physical premise.

## K6 review

PASS WITH STRICT DESCRIPTOR FIREWALL.

The hybrid route earns its place in the nondominated set only if the intermediate descriptor `q(P)` contains **source-certified probe information that exists before the physical-current law is chosen**.

Permitted descriptor content may include quotient-visible probe class, declared support/context, response window, source-visible representation/gauge channel, preparation/reset protocol class, and ledger/provenance metadata.

Forbidden descriptor content includes fitted current coefficients, measured transition frequencies, desired matrix elements, future outcome labels not available prospectively, or any encoding from which `J(P)` is recovered by definition.

With that guardrail, K6 genuinely separates a source-derived interface problem from a new physical-law problem.
