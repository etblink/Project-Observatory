## 4. Preregistration compliance

### 4.1 Evidence firewall

PASS.

The execution used NFC only to establish NFC architecture and PGH only to establish PGH architecture. The user's historical observation that PGH was inspired by the intuition that NFC branches are grammars was not used as proof.

### 4.2 Axis A — Generativity

PASS.

The execution distinguished NFC's source-descended realization architecture from PGH's more purely formal generation of a model class. It did not flatten both into the generic statement that they are rule-governed systems.

### 4.3 Axis B — Exclusion

PASS.

PGH-GRAM-0010 has qualified formal exclusion power: fixed triangle topology plus mutual source independence excludes a nondegenerate perfect-common-bit distribution while local kernels remain free. NFC branch legitimacy/admissibility and branch terminal conditions also exclude unlawful descendants or endpoint claims. The execution correctly bounded the different scientific meanings of those exclusions.

### 4.4 Axis C — Composition

PASS.

The execution identified real compositional structure on both sides while preserving differences in primitives: NFC uses POT morphisms, realization, transport/gluing and target-category structure; PGH-GRAM-0010 uses source-access topology and stochastic kernels.

### 4.5 Axis D — Identification/equivalence

PASS.

The execution correctly noted representation/identity machinery on both sides and incorporated PGH-DER-0006 / PGH-FAIL-0005 as an explicit warning that formal equivalence alone does not establish physical equivalence or physical selection.

### 4.6 Axis E — Derivation/dynamics

PASS.

The execution did not confuse permitted transformations or branch-local dynamics with actualization. It correctly observed that PGH's local kernels remain free and its bridge preserves multiple incompatible response laws, while accepted NFC audits leave universal actual-history selection unsupplied.

### 4.7 Axis F — Representation invariance

PASS.

Both architectures have nontrivial presentation-invariance machinery, but the execution correctly noted that Strong PGH demands a stronger cross-language representation-independence burden than has been established for NFC branches interpreted as grammars.

### 4.8 Axis G — No-smuggling

PASS AND DECISIVE FOR OUTCOME CLASS.

This axis supplies the strongest reason not to choose Outcome A.

NFC Book V allows declared branch-specific hypotheses provided they are visible, licensed, and non-hidden. Strong PGH imposes an additional explanatory accounting burden: if topology, scope, primitive structure, semantics, or another declared input performs substantive physical selection, that selective work must be charged and cannot be treated as law derivation merely because it is declared structurally.

Thus lawful NFC branchhood and successful Strong-PGH grammarhood are not the same acceptance criterion.

### 4.9 Axis H — Actualization

PASS.

No source-bound actualization law was found on either side. Current PGH-GRAM-0010 constrains a model class but does not choose local kernels, response law, or physical instantiation. NFC's accepted post-freeze finding likewise leaves actualization among admissible histories unsupplied.

### 4.10 Axis I — Null-law correspondence

PASS.

The execution treated NFC's missing actualization-law class and PGH-H0's `P = Select_L(W(G))` as a nontrivial structural analogy, not an identity. The scopes differ: NFC's result concerns actual-history selection within its audited architecture, while PGH-H0 concerns independent physical-law selection from grammatical well-formedness more generally.

The historical branch-as-grammar intuition is therefore scientifically useful when refined, not literally established.

`SHARED_FRONTIER = ADMISSIBILITY_OR_GENERATION -> PHYSICAL_SELECTION_OR_ACTUALIZATION`

These are not identical mathematical problems, but they are structurally adjacent enough to justify treating them as a cross-project Observatory frontier.
