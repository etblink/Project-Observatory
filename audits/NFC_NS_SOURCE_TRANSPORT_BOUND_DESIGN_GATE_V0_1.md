## Controlling distinction
The previously accepted source-transfer structure S(f_j) lawfully carries an exogenous source object from context U_j to U_{j+1}. The accepted local burden B_F(alpha,U_j) is profile-valued and constructed from the restricted source object. These facts suffice to define the next-context burden by re-evaluation:

B_{j+1}(alpha) := Q^{Pi,N,a}_{Res_{U_{j+1}}(S(f_j) alpha)}.

This is an exact typed transport schema. It does not imply a numerical inequality between B_{j+1} and B_j.

## New missing structure

Only after C_SOURCE is declared and licensed can one ask whether S(f_j) is isometric, nonexpansive, expansive with controlled gain, or satisfies an affine growth law.
