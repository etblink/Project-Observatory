## Question

What are the minimal genuinely distinct additional structures that could lawfully produce a probe-specific interaction/generator assignment `P -> V_P` while preserving the already accepted SPEC relational/ledger action, and which bridge class is the best first research target under equal adversarial scrutiny?

This gate selects a research target, not a truth verdict.

## Mandatory bridge classes

- `K1_PROCESS_REPRESENTATION_FUNCTOR`: add a functor/representation from the typed admissible-process category into an operator category, preserving composition and quotient equivalence.
- `K2_RH_STYLE_TRANSFORM_AGGREGATION`: add a source-descended transformation family on probes plus an independently licensed aggregation/weight law, reconstructing an operator as in the RH operator-origin pattern.
- `K3_LING_STYLE_ACTION_GRAMMAR`: add a finite typed action/grammar object that canonically refines probe composition before a separate representation step.
- `K4_PHYSICAL_INTERACTION_CURRENT`: add a branch-visible physical probe/current/interaction object in the YM/SM/SPEC arena so that `V_P` is a genuine interaction term or generator.
- `K5_DIRECT_RELATION_LINEARIZATION`: directly enrich `R_P` / `J_P^ledger` into an operator by choosing coefficient semantics on reachable edges.
- `K6_HYBRID`: any irreducible combination not reducible to the above.

## Evaluation axes

1. added physical assumptions;
2. added mathematical assumptions;
3. preservation of accepted quotient/ledger architecture;
4. compositional faithfulness;
5. resistance to hidden amplitude smuggling;
6. compatibility with SPEC/YM/SM operator arenas;
7. compatibility with RH/LING precedents without branch leakage;
8. prospective empirical/falsification exposure;
9. parameter/choice burden;
10. whether failure teaches something branch-independent.

## Mandatory reductions

If a class merely postpones an unavoidable representation choice, record it as a precursor rather than a complete bridge.

If two classes differ only by where the same coefficient/interaction law is declared, collapse them.

If a class embeds amplitudes into `V_P` without an independent representation principle, penalize it for hidden-weight risk.
