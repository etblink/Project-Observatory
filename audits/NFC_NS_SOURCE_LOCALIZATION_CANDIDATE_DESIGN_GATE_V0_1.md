## Source-side facts controlling the design
The frozen NS branch defines the active window family {W_k} from the additive-cumulative contraction profile of source-descended transport. Window size adapts to local contraction geometry rather than being fixed externally. Its averaging operator sums transport-indexed obstruction data over j in W_k with transport weights inherited from cumulative contraction factors.

Therefore W_k is not, at frozen scope, a primitive physical-space or physical-scale cell. A localization rule that simply identifies continuum support, Fourier scale, or decomposition level with k is ill-typed.

## Candidate adjudication
### L1 support-overlap incidence
Not directly available. It becomes coherent only after a map Xi_W assigns each transport/window element a certified represented physical/source context. Conditional viability: HIGH.

### L2 window-local pairing/restriction
Also requires Xi_W or an equivalent theorem telling which target-side test/localization data correspond to a window element. Conditional viability: HIGH and quantitatively useful once Xi_W exists.

### L3 transport-incidence localization
Most NFC-native at source level: a source component is incident to a window when its lawful transfer chain enters the represented context of that window. But this still presupposes a typed embedding of the exogenous-source family into the window contexts and a source-transport theorem. Conditional viability: HIGH.

### L4 scale-index identification
REJECTED. Physical scale/decomposition index is not the same type as transport-window index.

### L5 response-defined localization
REJECTED as primary localization. Absence of response does not imply absence of source; using response to infer presence would invert the source-to-response direction and permit post-outcome fitting.

### L6 arbitrary declared incidence
REJECTED for canonical force. Provenance alone does not derive the incidence relation.

## Minimal conditional schema
Introduce a distinct bridge

T_NS-WINDOW-REAL:
  w in union_k W_k -> C_w

where C_w is the certified source/continuum context represented by transport/window element w. Required properties: prospective declaration; quotient/presentation invariance; refinement compatibility; compatibility with the active contraction/adaptation law; no identification of physical scale with window index; and sufficient domain/support semantics to test source incidence.

Given T_NS-WINDOW-REAL and a lawful source representative F_src, define localization relationally:

alpha R_F w  iff  source component alpha is represented/present in C_w under the declared source-localization rule.

Then

S_F(W_k) = { (alpha, burden/provenance data) : exists w in W_k with alpha R_F w }.

A stronger quantitative version may use window-local pairings or restrictions, but only after the same realization bridge exists.

## Adversarial tests
1. Same support/different amplitude: PASS; incidence may agree while quantitative source burden differs.
2. Different scale/same support: PASS; no scale-index shortcut is allowed.
3. No visible response: PASS; source incidence is defined prospectively, not from response.
4. Equivalent source representations: requires T_NS-WINDOW-REAL and localization rule to respect representation equivalence.
5. Adaptive windows: source history is not rewritten when the window family adapts; the bridge maps each declared window state prospectively to its represented context.
6. OpenAI control: remains in scope; compact support alone does not imply harmless localization or regularity.

## Conclusion
Frozen NFC supplies the transport-window architecture but not the missing semantics that identify what physical/source context each adaptive window element represents. The localization problem is therefore not solved by support overlap alone. The next irreducible theorem burden is T_NS-WINDOW-REAL; after it, support/incidence and window-local pairing become coherent localization mechanisms.

No source-project mutation and no forced-regularity claim.
