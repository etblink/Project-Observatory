## Checked non-dependencies and reasoning firewalls

`OBS-DP002` prevents a category error between FCP taxonomy and PGH empirical truth.

`OBS-DP013` prevents a category error created by successful adversarial work: discovering a limitation or nonforcing result in Project Observatory is not the same act as amending NFC.

`OBS-DP014` prevents re-import of universal LS-2 after U002.

`OBS-DP015` prevents re-import of a strong historical/globalization no-go after U003. It does not invalidate Book-III synchronization holonomy or other exact scoped obstructions.

`OBS-DP016` is repository provenance discipline. It says nothing about the scientific truth of an acceptance artifact; it only protects commit reachability while manual branch pruning is performed.
