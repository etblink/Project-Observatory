## SPEC positive case

SPEC already supplies the closest NFC-native architecture to an ELCAK trial:

1. A declared observable object `X` in a certified observable class.
2. An admissible probe `P`.
3. A probe episode defined as an ordered application of `P` with a certified before/after response record.
4. A transition ledger recording the quotient-visible change `X -> X'`.
5. Conditional transition certification on the declared branch machinery.

This gives a natural candidate trial skeleton:

`parent response class + fixed probe -> one of prospectively frozen post-probe response classes`.

If a concrete physical realization can be bound, and if the post-probe outcome classes can be made mutually exclusive and collectively exhaustive before trials, then ELCAK would make the numerical prediction `1/k` for each of the `k` lawful siblings.

### Why SPEC still fails T3

The frozen branch explicitly says a probe episode is the spectroscopy analogue of a controlled admissible comparison and is **not yet a physical measurement event in the ordinary external sense**. The branch provides certified transition bookkeeping, not a concrete apparatus, reset protocol, repeated trial ensemble, physical sibling partition, or observed frequencies.

It also does not prove that all possible post-probe continuations from a declared parent are exhausted by a finite sibling set usable as an empirical multinomial outcome space.

Therefore upgrading SPEC to T3 requires more than analysis wording: it needs target realization and protocol construction.

## BIO positive case

BIO supplies a strong repeated-generation architecture:

1. The branch begins from a certified observable class of physical configurations and admissible probes.
2. Its replication kernel is quotient-visible and records which configurations produce certified copies of their own equivalence class.
3. Replication/heredity can be iterated, and the branch contains conditional discrete evolutionary dynamics over finite-stage population composition.
4. This makes BIO attractive for repeated observations and frequency accumulation.

A possible future ELCAK target could attempt to freeze a parent configuration class and define multiple lawful descendant/offspring outcome classes under a fixed generation protocol.

### Why BIO still fails T3

The foundational replication relation is intentionally **same-class copying**: a certified replication episode witnesses that the descendant belongs to the same observational equivalence class as the parent while recording the production process. That object does not itself supply a nontrivial set of alternative sibling classes.

The later evolutionary law supplies differential replication rates / population-composition dynamics under branch-specific conditions. Those rates cannot be reused as actualization probabilities without circularly importing a branch-local dynamical selector into the ELCAK test.

Thus BIO needs a new, independently justified branching observable that distinguishes prospectively enumerated offspring outcomes while remaining downstream of a fixed parent/generation protocol. It also requires an empirical realization and outcome-count protocol.

`BIO_T3 = NO`

## Why SPEC outranks BIO for first target construction

The comparison is not based on branch prestige or maturity. It is based on structural fit to the ELCAK object.

ELCAK is defined on a parent continuation state and its lawful post-interaction/post-observation children. SPEC already has an explicit transition architecture from a parent observable object under a controlled probe into a certified post-probe response class. BIO's primary repeated object is same-class replication, while its nontrivial population differentiation occurs later under branch-specific evolutionary dynamics.

Therefore SPEC requires fewer conceptual rewrites to define the exact sibling fork ELCAK needs.

BIO remains valuable as a secondary control because its repeated-generation structure can test whether any proposed SPEC protocol has accidentally relied on one-off measurement semantics rather than a genuine branching law.

## Minimal SPEC target-construction contract

A future SPEC feasibility operation should attempt to define, without collecting data:

1. one concrete realizable parent observable state `X_0`;
2. one fixed admissible probe/intervention `P_0`;
3. a finite quotient-visible outcome partition `{R_1,...,R_k}` of all admissible post-probe responses in a fixed window;
4. a reset/conditioning rule returning trials to the same parent-equivalence class;
5. a state record sufficient for future continuation or an explicit sufficiency hypothesis;
6. a prospective stopping rule / sample size policy;
7. ELCAK null `p_i = 1/k`;
8. a preregistered goodness-of-fit or likelihood decision rule;
9. exclusion rules and apparatus-failure states distinct from valid sibling outcomes;
10. a proof that none of 1-9 presupposes equal weighting.

No physical experiment should begin until this contract is closed.
