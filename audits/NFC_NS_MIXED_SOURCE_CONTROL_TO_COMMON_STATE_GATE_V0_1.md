## Finding
The accepted/provisional source architecture can be carried into the common-state program without type collapse by augmenting, not identifying, state components.

Let X_k denote the still-hypothetical frozen-NS common temporal state whose discharge must carry the window obstruction and contracting/coercive quantity on one temporal state space. Define the forced schema

X_k^F := (X_k, L_F(W_k), P_k^F),

where L_F(W_k) is the typed exogenous source ledger for the same active window and P_k^F denotes its profile/provenance state. Source evolution is governed separately by lawful source transport, the positive profile envelope Gamma, and the exact residual innovation profile J^res.

This augmentation does not discharge any pre-existing burden of the frozen common-state obligation. It merely places source data on the same declared window-indexed state record.

VIABLE / MINIMAL SCHEMA.

The full profile/ledger can be carried without scalarization. Window-context binding already supplies the typed contexts associated with j in W_k, so a separate physical-scale=window identification is unnecessary.

### C2 explicit source-to-endogenous coupling operator
REQUIRED FOR DYNAMICAL EFFECT.

To enter a continuation recurrence, the source data must act through a separately licensed bridge, schematically

C_k : SourceProfile(W_k) x EndogenousState(X_k) -> EndogenousBurdenOrRemainder_k,

or a source-only special case if independently justified.

A corresponding forced recurrence could then take a typed form such as

with

R_k^F = C_k(P_k^F, X_k),

or an equivalent state-evolution formulation. This display is a schema only, not a current theorem.

REJECTED. The source profile and endogenous defect/renewal objects live in different typed spaces. Direct addition would reproduce the kind of level/increment/type collapse already exposed by MIG-052.

### C4 identify source innovation with existing renewal inflow Psi_k
REJECTED. Existing renewal/inflow structure is endogenous to the current NS common-state proof program. Exogenous source innovation is not the same object absent a transfer/coupling theorem.

### C5 state-coupled work-injection bridge
PLAUSIBLE PHYSICAL INSTANTIATION, NOT DERIVED.

However it requires a lawful theorem connecting the source representation and continuum NS state to the endogenous burden/remainder used by NFC. It therefore belongs inside the future C_k design space rather than serving as present evidence.

### C6 no coherent augmentation
REJECTED.

## Relationship to frozen common-state obligation
The frozen obligation still separately requires:
- one common temporal state carrying obstruction and contracting/coercive quantity;
- a proved evolution law;
- uniform same-functional contraction with controlled remainder;
- two-sided same-state comparison;
- renewal control;
- a typed ledger-state map.

The forced extension adds source input to this architecture but proves none of those pre-existing items.

A lawful, prospectively specified coupling from typed exogenous source profile/provenance and, where physically necessary, the common endogenous state into the endogenous burden/remainder channel consumed by the forced continuation theorem.

Mandatory properties:
- source/endogenous types remain explicit;
- zero source gives zero source-induced remainder;
- representation/refinement invariance;
- component/provenance discipline;
- no endogenous-Theta reuse;
- no coefficients fitted to known regularity outcomes;
- explicit state dependence if used;
- declared failure conditions.

## Important consequence
The source-gain problem and the source-response problem are distinct. Gamma_j and J_j^res control how the external source itself evolves. They do not determine how strongly that source drives the fluid/obstruction state. The next scientific frontier is therefore source-to-endogenous coupling, not further refinement of source gain alone.
