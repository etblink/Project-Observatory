## Question
Given provenance-tracked source components localized to active contexts U_j, what is the weakest quantitative source burden object that can be attached prospectively to the source ledger without importing response information, dynamics-dependent work injection, or an unjustified scalar aggregation across scales?

## Candidate burden classes
B1 — restricted multiscale profile: Q_{alpha|U_j}^{Pi,N,a}, retaining component/scale entries.
B2 — one scalar norm of Res_{U_j}(alpha).
B3 — local work/energy injection such as <F,u> or its time integral.
B4 — defect-like count or event burden copied from endogenous NFC defect bookkeeping.
B5 — raw finite representation coefficients from one chosen dictionary.
B6 — no justified quantitative burden.

## Evaluation axes
- prospective computability from source data alone;
- context restriction compatibility;
- representation/dictionary invariance;
- addition/scaling behavior;
- support/provenance preservation;
- no endogenous-defect conflation;
- no response/state dependence;
- no arbitrary scale aggregation;
- ability to feed a later transport/source-control theorem;
- OpenAI negative-control compatibility.

## Mandatory adversarial tests
1. Same incidence, different amplitude must produce distinguishable burden data.
2. Same total scalar norm but different scale distribution must remain distinguishable unless a theorem proves equivalence.
3. Exact cancellation between components must not erase component burdens.
4. Dictionary changes reconstructing the same source must not alter the canonical burden object.
5. Bounded kinetic energy of the solution must not force small source burden.
6. Compact support alone must not imply small burden.
