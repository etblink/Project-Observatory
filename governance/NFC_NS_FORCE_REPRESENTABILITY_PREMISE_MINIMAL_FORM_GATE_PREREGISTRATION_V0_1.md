## Question
What is the narrowest nonvacuous post-freeze forcing class and representability premise worth testing prospectively as the new forced-NS input `P_NS-FORCE-REP`?

## Candidate forcing classes
- C1 all smooth forcing fields on the declared NS domain;
- C2 smooth compactly supported forcing fields on `R^3 x (0,T)`;
- C3 smooth compactly supported divergence-free forcing fields;
- C4 forces small in a preselected norm;
- C5 only forces generated by an NFC-internal admissible process;
- C6 a finite-dimensional handpicked source family.

## Candidate premise strengths
- P1 bare existence of some representative;
- P2 faithful representation preserving provenance/support/decomposition;
- P3 P2 plus zero, addition, and scalar-rescaling compatibility wherever the physical forcing class supports those operations;
- P4 P3 plus window localization;
- P5 P3 plus source transport/continuation control.

## Selection criteria
The preferred class/premise must:
1. be physically/mathematically natural independently of the known OpenAI outcome;
2. include enough nontrivial forcing variation to be falsifiable;
3. avoid assuming smallness/safety in the class definition;
4. preserve source identity and support;
5. preserve the natural additive/scaling structure when lawful;
6. remain upstream of localization, transport weighting, and continuation;
7. include the frozen OpenAI construction only if it belongs for an independently stated reason;
8. avoid unnecessarily broad universal claims.
