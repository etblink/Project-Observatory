## Question
Assuming only provisionally that a smooth compactly supported physical forcing F has a faithful lawful EXOGENOUS_SOURCE_FAMILY representative F_src, what is the weakest noncircular localization structure that maps F_src into the existing NFC NS window architecture without identifying continuum scale, spatial support, or time support with an NS window index by fiat?

## Candidate localization classes
L1 — support-overlap incidence: alpha R W_k when certified realized support of source component alpha overlaps the realized support/domain represented by W_k.
L2 — partition-of-unity / local pairing localization: window-local source content obtained by pairing/restricting F_src against certified window-local observable/test data.
L3 — transport-incidence localization: source component belongs to W_k when it participates in a declared lawful transfer chain entering the window context.
L4 — scale-index identification: map physical decomposition scale j directly to window index k.
L5 — dynamics/response-defined localization: infer window membership from where source changes the NS response.
L6 — arbitrary declared incidence relation with provenance but no derivation.
L7 — no justified localization candidate.

## Mandatory adversarial tests
1. Two forces with same physical support but different amplitudes must localize to same incidence support while remaining quantitatively distinguishable downstream.
2. Two forces at different physical scales but same support may not be assigned to different windows solely from scale label unless an independent theorem licenses it.
3. A force that produces no visible response in a window may still be physically present there; response absence cannot define source absence.
4. Equivalent source representations must induce equivalent localization.
5. Window adaptation caused by solution evolution may not retroactively redefine where the source was.
6. OpenAI smooth compactly supported forcing stays in scope without fitted exclusions.
