## Finding
The accepted witness-mass evolution shows that interface stock is genuinely memory-bearing. For a complete lawful identity transfer with no new boundary generation,

M_{n+1}=M_n,

so active interface distinctions may persist unchanged across a step. Current boundary-generation mass can simultaneously vanish. More generally,

M_{n+1}=M_n-L_n^q-X_n^mig-C_n^merge+G_n^eff,

with 0<=G_n^eff<=B_n.

Thus the current interface stock depends on retained historical witness mass as well as current generation. It is not a function of the current step-defect ledger alone.

Conditional active-load equivalence transfers that memory character to I_n, and hence to S_k=A_k(I).

By contrast, Z_k=mathfrakD_k is conditionally realized from the active average of the current visible finite-balance ledger. Therefore a universal same-window static proportionality S_k~Z_k is not forced by existing structure.

## Adversarial countermodel shape
Take an already nonzero active interface witness family. Apply a complete identity/boundary-preserving lawful transfer with no new generation and no quotient/migration/merge loss. Then M persists. If the current step introduces no new finite-balance defect, the current defect increment can vanish while interface stock remains nonzero.

This is sufficient to defeat any source-forced universal upper comparison

S_k <= C Z_k

unless an additional stock-turnover/current-load hypothesis excludes such persistence in the declared comparison regime.

The exact numerical compatibility of this control shape with every downstream NS threshold hypothesis is not asserted; its role is to show that stock persistence is independent structural data and cannot be erased by definition.
