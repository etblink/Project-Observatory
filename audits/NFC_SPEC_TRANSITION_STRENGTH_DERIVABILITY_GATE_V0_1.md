## SPEC audit

### Allowed modes vs weighted modes

SPEC's Generator Compatibility theorem establishes that the response family is compatible with the operator packet and induces transition-accessible spectral packets. The discharged form identifies each response class with a quotient-visible spectral mode of `L_Spec` and the transition-accessible packets with the branch-visible subset of `Spec(L_Spec)` exercised by admissible probes.

This establishes **accessibility and mode identity**.

It does not assign relative strengths among multiple accessible modes.

`ALLOWED_CHANNEL_DERIVATION = YES`

`RELATIVE_WEIGHT_DERIVATION = NO`

### Transition ledger

SPEC's transition ledger records certified response change under a probe episode and declared transport/visible-defect bookkeeping.

The branch explicitly states that ledger additivity is bookkeeping additivity, not physical intensity or amplitude additivity.

Therefore no channel probability follows from ledger magnitude or additivity without a new theorem.

### Spectral locations, gaps and margins

SPEC contains spectral data and a spectral margin measuring resonance isolation/response separation/transition distinguishability. YM supplies a spectral gap and coercive structure.

These quantities can identify modes, separations and stability regimes. No frozen theorem maps spectral location or gap alone to relative transition strength.

`EIGENVALUE_TO_WEIGHT_BRIDGE = ABSENT`

### Response signatures

Response classes are quotient-visible and operator-compatible. A response signature certifies that a mode is visible to the declared probe. It does not, in the frozen theorem stack, provide a frequency-of-occurrence or rate coefficient for transitions into that mode.

`RESPONSE_TO_RATE_BRIDGE = ABSENT`

## Why Outcome E is not selected

This audit does **not** establish that standard external quantum physics is logically required forever. An expanded NFC could in principle derive a new branch-visible coupling object from existing or new primitives.

Therefore the stronger claim

`E__EXTERNAL_STANDARD_PHYSICS_IMPORT_REQUIRED_AT_CURRENT_SCOPE`

is not adopted as the primary outcome.

The narrower accepted scientific statement is that the **current frozen stack requires a new branch-specific dynamical bridge** if it is to predict relative transition strengths.

## Minimal missing bridge object

The smallest missing object is a branch-visible **Transition Coupling Object** `M_SPEC` with the following role:

`M_SPEC(parent, probe, child_i) -> a_i`

where `a_i` is a prospective channel-coupling quantity, together with a theorem that produces nonnegative physical strengths

`W_i = F(a_i, source/branch data)`

and normalized probabilities

`P_i = W_i / sum_j W_j`.

The bridge must satisfy:

1. source/branch descent and no-hidden-supplementation;
2. quotient visibility / representation invariance;
3. prospective computability before target frequencies;
4. no channel-specific free parameters fitted to those frequencies;
5. explicit scope and failure conditions;
6. ability to reproduce or fail against already-known spectroscopy quantitatively.

This object is deliberately stated abstractly. It is not assumed to be a quantum matrix element unless a future derivation proves that identification.
