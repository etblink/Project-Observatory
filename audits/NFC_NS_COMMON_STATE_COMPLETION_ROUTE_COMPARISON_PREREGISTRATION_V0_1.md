## Purpose

Close the current NFC Navier–Stokes common-state investigation by comparing the remaining scientifically honest completion routes after the accepted finding that frozen NFC permits invariant active interface stock and therefore does not source-force a universal active-stock turnover law.

This gate is a stopping/route-selection gate. It is not authorization to add new NFC axioms, alter frozen NFC canon, modify the NS branch, claim Navier–Stokes regularity, or continue indefinite branch development inside Project Observatory.

## Frozen inputs

The comparison must preserve all accepted upstream findings, including:

1. the direct obstruction recurrence is not source-forced for `O_k = S_k - J_k` without cross-channel control;
2. the signed event-flow architecture has the schematic form

   `Delta O = -R^S + G^S + Phi - Psi - Delta^win + sigma`;

3. H1/H2 supply genuine eventwise quotient-loss / mixing mechanisms but no source-forced positive fraction of the active-stock population is certified to enter those loss classes;
4. active quotient-visible stock may remain invariant under lawful transfer;
5. therefore universal stock turnover/noninvariance is new branch-specific dynamics if introduced.

## Candidate completion classes

### Route A — New branch-specific stock dynamics

Add a separately declared, prospectively testable condition controlling active-stock resolution, turnover, or bounded-block noninvariance strongly enough to dominate dangerous signed drift. Examples include a per-step or blockwise lower bound on resolved active stock relative to active stock or to the positive drift channels.

The comparison must not assume such a condition is true merely because it would close the recurrence.

### Route B — Memory-aware common-state representation

Retain potentially persistent interface stock as an explicit state component and seek a vector-valued or memory-aware Lyapunov/comparison object rather than forcing scalar recurrence directly on `O=S-J`.

This route succeeds only if it can control the existing canonical obstruction without silently reintroducing a stock-decay hypothesis. A change of coordinates alone does not count.

### Route C — Redefine/rebase the NS obstruction

Replace or materially alter the canonical obstruction functional so inherited stock is treated differently.

This route must be classified as a canon-changing program unless an exact equivalence theorem preserves all downstream consumers. Prior frozen source explicitly records that an incremental reformulation changes the obstruction definition and rebases downstream consumers.

### Route D — Stop at frozen-source boundary

Conclude that no present route closes the existing common-state frontier from frozen source alone; record the minimum new scientific premise or canon change required and return Project Observatory to its cross-project mission without selecting a speculative completion theory.

## Evaluation axes

Each route will be judged on:

- consistency with accepted frozen-source findings;
- ability to defeat the invariant-stock countermodel;
- whether it controls the existing canonical obstruction rather than a substitute quantity;
- amount of genuinely new scientific content required;
- falsifiability / empirical or mathematical exposure;
- preservation of existing NS branch semantics and downstream consumers;
- circularity risk;
- proof burden;
- suitability for Project Observatory versus source-project development.

## Critical countermodel

Any route claiming closure must survive the admissible persistent-stock case in which active stock remains positive and quotient-visible while current ledger defect decreases. A representation that merely renames this state does not defeat the countermodel.
