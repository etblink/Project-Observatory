## Question

Does the frozen NFC corpus, using the accepted `Path_SPEC` reconstruction and the existing SPEC operator packet, generator-compatibility theorem, Book-V realization-functor architecture, and source-equivalence discipline, jointly license a concrete operator/semigroup target category strongly enough that the target counts as source/branch-selected rather than merely mathematically chosen?

## Scope

This gate is representation-theoretic only. It does not derive physical coupling coefficients, transition amplitudes, transition probabilities, a physical interaction current, or an actualization law. It does not mutate frozen NFC canon, FCP science, or PGH science.

## Licensing criteria

A target counts as licensed only if all are satisfied:

- **L1 Source descent:** target structure is explicitly sourced through frozen NFC descent machinery.
- **L2 Branch declaration:** SPEC or a declared import already fixes the relevant target arena rather than merely permitting one.
- **L3 Functorial fit:** certified probe/path composition can land functorially in the target.
- **L4 Quotient invariance:** source-equivalent presentations map to equivalent target objects/operators.
- **L5 No hidden supplementation:** scalar field, topology, inner product, positivity, adjoint, completion, phase or normalization are not silently imported.
- **L6 Operator-packet compatibility:** target is compatible with the frozen SPEC operator packet and generator-compatibility theorem.
- **L7 Nontriviality:** target does more than restate Boolean reachability.
- **L8 Target specificity:** evidence selects the concrete target class, not just a broad family of possible target categories.

## Mandatory adversarial tests

1. **Permission-vs-selection test:** Book V permission for operator/semigroup categories is not target selection.
2. **Free-linearization test:** universal construction after choosing `k` is not evidence that NFC chose `k`.
3. **Real-vs-complex test:** if both real and complex realizations preserve frozen theorem truth, neither is source-forced absent an additional theorem.
4. **Hilbert-completion test:** finite/operator data do not automatically license a Hilbert completion.
5. **Adjoint/positivity test:** self-adjointness, positivity, contractivity or semigroup generation must be frozen claims, not conventional spectroscopy assumptions.
6. **Existing-operator-packet test:** distinguish the target arena of `L_SPEC` from a representation of generic probes.
7. **YM-import test:** YM structures may constrain a target only at the explicitly imported domain/scope.
8. **SM-import test:** matter extension may enlarge the arena without selecting the probe representation target.
9. **RH-precedent test:** architectural precedent cannot transfer Mellin/arithmetic target semantics into SPEC.
10. **Conservative-target test:** exhibit at least two inequivalent target enrichments preserving accepted `Path_SPEC` semantics if possible.

The audit must cite frozen canonical source. Mathematical constructions may be used to test nonuniqueness, but they do not acquire NFC theorem force unless supported by frozen source. Conventional quantum/spectroscopic practice is not evidence unless separately licensed by the corpus.
