## 4. Frozen comparative question

> To what extent does the formal role of an NFC branch correspond to the formal role of a PGH grammar, and does either architecture contain a principled actualization layer that the other lacks?

Subquestions:

1. Does an NFC branch behave like a generative grammar over admissible structures/histories, or only like a realization-specific constraint package?
2. Do NFC branch ingredients map nontrivially onto PGH grammar ingredients such as types/distinctions, contextual constraints, composition, equivalence/identification, and permitted derivations?
3. Is NFC branch legitimacy/admissibility structurally analogous to PGH grammatical well-formedness/exclusion?
4. Does SCC's recursion/canonicalization look like grammar closure rather than physical actualization?
5. Does the accepted NFC missing-object class `ACTUALIZATION_LAW_OVER_ADMISSIBLE_HISTORIES` correspond structurally to PGH's live-null possibility that an independent law set `L` must still perform substantive selection?
6. Does PGH-GRAM-0010 provide anything that would fill NFC's actualization gap, or does it operate at the same admissibility/generative layer?
7. Conversely, do NFC branch constructions reveal structure that PGH would classify as smuggled physics rather than grammar?
8. Is any apparent NFC↔PGH correspondence representation-independent and nontrivial, or is it generic formal resemblance?

## 9. Mandatory adversarial readings

### Pro-Correspondence reading

Construct the strongest defensible mapping in which each NFC branch is a grammar-like object: branch data define well-formedness, lawful composition/continuation, equivalence, exclusion, and generated/realized structures.

Identify every point where this mapping is theorem-supported rather than metaphorical.

### Anti-Correspondence reading

Assume the resemblance is superficial. Attempt to show that NFC branches are realization packages over already-supplied physics while PGH grammar aims to make substantive physical possibility arise from grammar itself. Test whether branch-specific assumptions simply relocate the independent law set that PGH-S forbids.

### Actualization reversal

Assume one architecture contains the missing actualization layer. Search explicitly for it. The crosswalk may claim such a layer only if it identifies a noncircular source-bound selector mechanism meeting the accepted NFC selector criterion.
