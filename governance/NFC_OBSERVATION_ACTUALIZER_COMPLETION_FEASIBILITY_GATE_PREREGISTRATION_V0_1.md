## 3. Frozen question

Can observation become physically efficacious inside NFC without violating NFC's own rule that admissible observation cannot canonically distinguish what remains observationally indistinguishable?

Equivalently: is there a source-motivated completion architecture in which an internal test/witness changes the licensed physical/history state so that the post-observation distinction is itself quotient-visible, rather than selecting an otherwise hidden representative from behind a many-to-one quotient?

## 4. Required distinction

The audit must keep separate:

1. OBSERVATIONAL_REFINEMENT — a test changes/refines the equivalence relation or quotient description;
2. CONDITIONAL_RESTRICTION — given an observed outcome, histories inconsistent with that outcome are excluded;
3. PHYSICAL_BACKACTION — performing the test changes the lawful physical/history state or future admissible continuation class;
4. ACTUALIZATION — the observation-linked physical process selects or weights which post-test history is physically realized;
5. HIDDEN_INVERSE_SELECTION — a rule simply picks one pre-existing representative from an observational equivalence class without a newly licensed distinguishing fact.

Only (3)+(4), with no (5), can qualify as an observation-triggered actualizer.

## 5. Candidate mechanism classes to test

M1 — QUOTIENT_REFINEMENT_ONLY
Observation changes the licensed partition/equivalence description but does not physically change the underlying admissible history set.

M2 — TEST_AS_ADMISSIBLE_PHYSICAL_PROCESS
Because NFC tests are admissible relational processes, test execution may itself be a physical process whose output/state is part of the subsequent configuration.

M3 — WITNESS_RECORD_CREATION
Observation creates a persistent quotient-visible record, making formerly indistinguishable continuations distinguishable after the interaction.

M4 — DEFECT_OR_LEDGER_BACKACTION
Observation changes defect/transport bookkeeping in a way that constrains later survivor chains or admissible continuations.

M5 — BRANCH_OR_ENDPOINT_BACKACTION
Observation produces branch-visible endpoint structure or changes the lawful branch realization/continuation class.

M6 — RECURSIVE_OBSERVATION_FILTRATION
Successive internal observations generate a nested filtration whose intersection may isolate one post-interaction history class.

M7 — OBSERVATION_WEIGHTING
The witness machinery induces a source-forced normalized weighting/kernel over post-observation histories.

M8 — HIDDEN_REPRESENTATIVE_PICK
Observation merely chooses one representative already collapsed by the quotient. This is expected to fail NFC's anti-inversion/no-identity-smuggling discipline unless the source itself supplies a new licensed distinction.

## 6. Qualification criteria

A candidate observation-actualizer must satisfy all of:

Q1 SOURCE_MOTIVATION — its ingredients are already motivated by frozen NFC objects/rules rather than imported ontology.
Q2 PHYSICAL_EFFICACY — test execution changes the lawful physical/history state or continuation structure, not merely the observer's description.
Q3 QUOTIENT_VISIBILITY — the post-test selected distinction is licensed in the resulting observational structure.
Q4 NO_HIDDEN_INVERSE — it does not canonically invert a many-to-one quotient without new physical/observable information.
Q5 NONCIRCULARITY — the mechanism does not assume the actual outcome/history it is supposed to produce.
Q6 HISTORY_FORCE — it genuinely selects or weights post-test histories, not merely classifies them.
Q7 REPRESENTATION_INVARIANCE — the result does not depend on raw labels or presentation surplus.
Q8 PROVENANCE_VISIBILITY — all extra hypotheses are explicit; undeclared supplementation is disqualifying.
Q9 SOURCE_OR_DECLARED_SCOPE — any universality claim must be source-forced; branch-local mechanisms may qualify only as branch-local completion candidates.
Q10 FAILURE_EXPOSURE — the mechanism has an explicit condition under which it fails.

## 7. Key anti-smuggling test

At a singular quotient class containing distinct configurations omega_1 and omega_2, NFC forbids a canonical inverse selector based solely on information already erased by observational equivalence.

Therefore a viable observation actualizer must have the form

pre-test quotient-visible state
  + admissible test interaction
  -> newly generated quotient-visible physical record/state/constraint
  -> post-test lawful history selection or weighting

and not

pre-test quotient class
  -> arbitrary hidden choice of omega_i.

## 8. Recursive-filtration test

If successive tests generate nested history classes

H >= H_1 >= H_2 >= ...,

the audit must determine whether frozen NFC proves any of:

- finite singleton termination;
- asymptotic singleton/equivalence-class isolation;
- canonical normalized weighting on the limiting intersection;
- or only eventual stabilization at a potentially non-singleton quotient class.

Stabilization alone is not actualization.

## 9. Mandatory adversarial reversals

### Pro-actualizer reversal
Construct the strongest source-supported chain from internal test -> physical process -> persistent record/backaction -> changed continuation class -> actualization. Identify exactly where each implication is theorem-level, conditional, or absent.

### Anti-actualizer reversal
Construct a lawful model in which all frozen observational/refinement/transport theorems hold, observation produces quotient-visible records and can affect later observable state, yet multiple physically distinct post-test histories remain. If such a model is compatible with the source, observation-triggered actualization is not source-forced.

## 11. Decision rule

Prefer the strongest positive outcome justified by theorem-level source support, but do not infer actualization from physical efficacy alone.

Outcome C is specifically reserved for the case where tests can be shown to be physically efficacious processes that create/change quotient-visible structure while history-level multiplicity survives.

Outcome E requires more than failure to find a selector: it requires showing that every source-motivated route to observation actualization necessarily violates the anti-inversion rule.
