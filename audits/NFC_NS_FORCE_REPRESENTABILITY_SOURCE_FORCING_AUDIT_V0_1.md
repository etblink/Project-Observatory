## Source-lane findings

### Book I — admissible processes/tests
NO SOURCE FORCE.

Book I begins from a purely finite relational setting and explicitly forbids primitive spacetime, metric, probability space, or background field. Its extension processes and tests operate on the admitted relational configuration arena and must satisfy anti-smuggling constraints. Nothing in A1–A4 says that an arbitrary target-side physical forcing field admits a source-descended representative.

Admissibility of a test/process therefore cannot be promoted into representability of an external continuum source.

### Book III — persistence/transport
NO SOURCE FORCE.

Book III defines persistent observables, transfer maps, transport classes, flux/accounting, and coercive transport for already-certified observable content. Its transfer laws preserve or compare certified content; they do not create a branch-visible external source object from an arbitrary physical field.

Thus Book III can support later source transport only after source realization has been independently established.

### Book IV — universal source/factorization
NO SOURCE FORCE.

The universal-source architecture constrains lawful descendants to factor through the source. It does not imply that every target-side physical object has a lawful preimage/realization. Reading universal factorization as target-surjectivity would reverse the direction of the theorem and violate the anti-smuggling discipline.

### Book V — realization functors and branch legitimacy
NO SOURCE FORCE; FUNCTOR IS PRESUPPOSED.

Book V defines a realization functor as a functor from POT into a licensed target category that is itself licensed by an explicit bridge theorem. The Branch Projection and Legitimacy results then certify descendants under that already-declared functor.

Therefore Book V does not prove `P_NS-FORCE-REP`; it precisely marks the place where such a bridge must be supplied.

### Book VI — continuum interface
PARTIAL SUPPORT ONLY.

Book VI supplies the generic interface machinery needed to represent certified structures in continuum language, but explicitly states that it does not identify which observable families satisfy the interface hypotheses; that burden remains branch-dependent.

This gives the language and validation criteria for a forcing representation, not the existence theorem.

### Frozen NS branch
NO FORCE-REALIZATION THEOREM IDENTIFIED.

The NS branch contains source-descended observable/defect/continuation structures and continuum NS identification. It does not contain a theorem taking a prospectively prescribed external forcing field `F(x,t)` and constructing a lawful exogenous-source representative with preserved provenance/support/scale data.

The current unforced balance/regularity architecture therefore cannot be repurposed as such a theorem without new branch-specific content.
