## Dependency reconstruction

### A — common temporal state
LOGICALLY PRIOR BUT NOT THE PRIMARY THEOREM TARGET.
A formal product record can be written, but without B/F it has no canonical dynamical force. Treating mere co-indexing as discharge would repeat the stock/increment error that MIG-052 removed.

### B — interface-burden/state evolution
SELECTED FIRST TARGET.
Book III defines I_n as the total certified collar defect load at stage n, while B_n is the certified boundary-defect increment generated during the step U_n -> U_{n+1}. The UCTI evolves the combined functional C_n = B_n^bulk - I_n but does not separately provide an evolution law for the stock I_n. The frozen common-state obligation explicitly names this absence.

A lawful I_n evolution would expose all retained, newly generated, migrated, and genuinely lost boundary burden channels. That accounting is a prerequisite for a noncircular common temporal state and for any same-state contraction argument.

### C — uniform contraction
DOWNSTREAM.
The frozen obligation already requires a proved evolution law before a uniform same-functional contraction can be certified. Attacking C first would force assumptions about the missing dynamics.

### D — two-sided same-state comparison
DOWNSTREAM OF A/B AND LIKELY F.
Without a typed common state and evolution law, comparing O_NS(W_k) with the contracting branch quantity risks comparing a level stock to an increment or transported surrogate.

### E — total-renewal control
HIGH LEVERAGE BUT NOT FIRST.
The branch has partial/boundary-only structure and hypothetical renewal routes, but total-renewal control alone does not supply the missing ledger-to-branch transfer or interface-stock evolution.

### F — ledger-state map
SECOND-HIGHEST TARGET.
Existing canon contains a useful ledger-side recurrence, and F would transfer that structure to the branch state. However a map into a branch state whose interface burden has no proved evolution is underdetermined. B should therefore precede F.

### UWB
SEPARATE SCOPE HYPOTHESIS.
Important for the current variable-window global-uniformity route, but solving it would not discharge the common-state type/evolution defect. It is not the first attack.

## Why B dominates information value
1. It attacks an explicitly absent theorem rather than tuning a downstream inequality.
2. Failure would invalidate major portions of the current near-closure architecture early.
3. Success supplies typed dynamics needed by A, D, F and ultimately C.
4. It can be studied through finite collar/transfer accounting already present in Books II-III, without importing forced-source assumptions.
5. It directly addresses the level-stock versus step-increment distinction that caused the prior alpha withdrawal.

## Candidate structural form to test next
A legitimate interface-burden law would have to look schematically like

I_{n+1} = T_n^I[I_n] + G_n^bdry + M_n^{int->bdry} - L_n^bdry,

or an inequality/equivalent finite-balance form, where:
- T_n^I is retained/transported prior interface burden;
- G_n^bdry is genuinely new collar/boundary burden generated during the step and must be related carefully to, but not identified blindly with, B_n;
- M_n^{int->bdry} records lawful migration into the interface if present;
- L_n^bdry is a genuine loss/removal channel;
- all terms live on the same stage-to-stage accounting and are derived from certified collar/transfer data.

This is a candidate accounting schema only, not a theorem.
